### Story

*As a Crawler Agent, I want to save the structured data extracted by the AI into the SQLite database, so that the data is permanently stored for later use.*

### Acceptance Criteria

1.  After the AI successfully populates the Pydantic model, the application connects to the SQLite database.
2.  A new record is inserted into the `scraped_data` table.
3.  The data in the newly inserted record correctly matches the data from the Pydantic model.
4.  The application logs a success message indicating that the record has been saved.

### Dev Notes

*   **Data Serialization:** The `image_urls` field is a list in our Pydantic model but needs to be stored as a single text field in SQLite. It must be serialized into a JSON string before insertion. *(Source: docs/architecture.md#4-data-models-and-schema)*
*   **SQLAlchemy:** Use SQLAlchemy for the database insertion to ensure security and maintainability. Avoid writing raw SQL strings. *(Source: docs/architecture.md#2-technology-stack)*
*   **Connection Management:** Database connections should be opened and closed for each transaction to keep the logic simple for this single-threaded application. *(Source: Story 1.6 Implementation Plan)*

### Tasks / Subtasks

1.  **(AC: 1, 2, 3)** Implement the `save_scraped_data(db_path, data)` function in `src/database/persistence.py`. This function will connect to the database and insert a new record into the `scraped_data` table.
2.  **(AC: 1, 4)** In `crawler.py`, after a successful AI extraction, call the `save_scraped_data` function, passing the database path and the populated `ScrapedData` model.
3.  **(AC: 4)** Log a success message to the console after the database operation is complete.
4.  **(Testing)** Add a unit test in `tests/test_persistence.py` to verify that the `save_scraped_data` function correctly saves a sample object to an in-memory database.
