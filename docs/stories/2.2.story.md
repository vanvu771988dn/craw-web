### Story

*As a User, I want the extracted content to be rewritten by an AI, so that it is easier to read and understand.*

### Acceptance Criteria

1.  After the main content is successfully extracted, it is passed to a new AI processing step.
2.  A new prompt is engineered specifically for the task of simplifying and rephrasing text.
3.  The rewritten, "enhanced" content is saved to a new `enhanced_content` field in the `scraped_data` table in the database.
4.  The `ScrapedData` Pydantic model is updated to include the new `enhanced_content: str` field.
5.  The process gracefully handles and logs any errors that occur during the AI enhancement step.

### Dev Notes

*   **Separation of Concerns:** This enhancement is a post-processing step. It should be triggered *after* the primary content extraction is complete. *(Source: docs/architecture.md#5-core-logic-and-workflow)*
*   **Prompt Engineering:** The quality of the simplified content will depend heavily on the prompt. It should be tested and refined to produce consistently good results. It should be stored in a manageable way, perhaps in the `crawler.py` module for now.
*   **Database Migration:** The database schema will change. The `init_database` function in the `persistence` module will need to be updated to include the new `enhanced_content` column in the `scraped_data` table.
