### Story

*As a Crawler Agent, I want to robustly handle complex navigation patterns and interruptions (like cookie pop-ups), so that I can reliably reach and prepare the final content page for extraction.*

### Acceptance Criteria

1.  The crawler can successfully navigate to the final destination URL for all three specified scenarios.
2.  The crawler automatically detects and clicks common cookie consent buttons after page load.
3.  After final navigation, the raw HTML is cleaned using `BeautifulSoup` to remove all `<script>` and `<style>` tags.
4.  The logic for identifying the redirect button (e.g., by a CSS selector) is configurable.
5.  The waiting time for timed redirects is configurable.
6.  If navigation or cleaning for a specific link fails, the URL and reason are logged to the `error_logs` table in the SQLite database.

### Dev Notes

*   **Configuration:** Navigation parameters (selectors, wait times) must be externalized to `config/config.yaml` to avoid hardcoding. *(Source: PRD - NFR3)*
*   **HTML Cleaning:** The final page HTML must be pre-processed to remove noise before being sent to the AI. `BeautifulSoup` is the approved tool for this. *(Source: docs/architecture.md#5-core-logic-and-workflow)*
*   **Error Persistence:** Navigation errors must be persisted to the SQLite database. This requires a dedicated function in the `persistence` module. *(Source: docs/architecture.md#6-error-handling-and-logging)*

### Tasks / Subtasks

1.  **(AC: 4, 5)** Update `config/config.yaml` with selectors for content links, buttons, and wait time parameters.
2.  **(AC: 1)** In `crawler.py`, refactor the `run_crawl` function to extract a list of content links from the start page.
3.  **(AC: 1, 6)** Create a new internal function, `_navigate_to_destination`, and loop through the content links, calling this handler for each one inside a `try...except` block.
4.  **(AC: 1, 4, 5)** Implement the logic within `_navigate_to_destination` to handle the three navigation scenarios using `Crawl4AI` and Playwright features.
5.  **(AC: 2)** Add logic within `_navigate_to_destination` to find and click general-purpose cookie consent buttons after the page loads.
6.  **(AC: 3)** Add a step within `_navigate_to_destination` to parse the `final_html` with `BeautifulSoup` and remove script and style tags.
7.  **(AC: 6)** Implement the `log_error` function in `src/database/persistence.py` to save failed navigation attempts to the `error_logs` table.
