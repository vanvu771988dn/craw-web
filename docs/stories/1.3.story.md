### Story

*As a Crawler Agent, I want to navigate to the initial list-view URL, so that I can begin the crawling process.*

### Acceptance Criteria

1.  The application reads the start URL from the configuration file.
2.  The application uses `Crawl4AI` to launch a browser and navigate to the start URL.
3.  The application successfully retrieves and logs the title of the list-view page to confirm a successful connection.
4.  The application correctly handles and logs a basic navigation error (e.g., an invalid URL).

### Dev Notes

*   **Core Framework:** All browser interactions will be handled by the `Crawl4AI.AsyncWebCrawler` class. *(Source: docs/architecture.md#2-technology-stack)*
*   **Entry Point:** The main crawling logic will be housed in `src/core/crawler.py` and orchestrated from `src/main.py`. *(Source: docs/architecture.md#3-directory-and-code-structure)*
*   **Asynchronous Execution:** The crawling process is asynchronous and must be run using `asyncio`. *(Source: docs/architecture.md#5-core-logic-and-workflow)*

### Tasks / Subtasks

1.  **(AC: 2)** Create the `src/core/crawler.py` module.
2.  **(AC: 1, 2)** Implement an async function `run_crawl(config)` that initializes `AsyncWebCrawler` and navigates to the `start_url` from the config.
3.  **(AC: 3)** Upon successful navigation, log the page title from the `CrawlResult` metadata to the console.
4.  **(AC: 4)** Wrap the navigation call in a `try...except` block to catch and log any exceptions to the console.
5.  **(Orchestration)** Update `src/main.py` to import and call `run_crawl` using `asyncio.run()`.
